# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| Earlier versions | No |

## Reporting a Vulnerability

Please report suspected security vulnerabilities by using GitHub private
vulnerability reporting for this repository:

https://github.com/Portvgal/moodle-local_checklistsettings/security/advisories/new

Do not report security vulnerabilities through public GitHub issues. Public
issues are appropriate for ordinary bugs, feature requests, and documentation
improvements.

When reporting a vulnerability, include the affected plugin version, Moodle
version, reproduction steps, expected impact, and any relevant configuration
details. Reports are reviewed privately, and updates are provided as practical
while the issue is triaged and fixed.
